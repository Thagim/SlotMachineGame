# Slot Machine Game

## Game Overview
A Unity slot machine game developed using C# and Unity 6.

## Instructions to Run WebGL Build
1. Open the Build/WebGL folder.
2. Run the game using a local server or GitHub Pages.

## Bonus Features
- Lever animation
- Popup win message
- Random symbol generation

## Approach
Implemented the slot machine using Unity UI Images and C# scripts with random sprite selection.

## Folder Structure
Assets/Scripts/
Assets/Prefabs/
Assets/Animations/
Assets/UI/
Assets/Sounds/

## Built With
- Unity 6
- C#
- TextMeshPro
